# ☁ Облачный остров — Roblox-мини-игра в одном LocalScript

Вся игра живёт в **одном LocalScript** (`CloudIsland.client.lua`): она строит
остров в небе, расставляет декор и настраивает закатный свет прямо на клиенте.
Серверные скрипты не нужны.

## Как запустить

1. Открой **Roblox Studio** и создай место по шаблону **Baseplate**.
2. В окне **Explorer**: `StarterPlayer` → `StarterPlayerScripts` →
   **Insert Object** → `LocalScript`.
3. Открой новый LocalScript и вставь туда код из
   `CloudIsland.client.lua`.
4. Нажми **Play** (F5) — остров, облака и свет создадутся автоматически.

Во время игры все объекты лежат в `Workspace → CloudIsland`.

### Если файл слишком большой для копирования

Полный скрипт большой, поэтому он же разбит на 6 маленьких частей
в папке `parts/`. Каждую часть копируй отдельно и вставляй **по порядку
в один и тот же LocalScript**: `part1.lua` → `part2.lua` → … → `part6.lua`.
Шапки-комментарии в начале каждой части можно оставить — они не мешают.

## Что внутри

- **Остров**: травяной блин, слой земли, скальный шпиль внизу с неровным
  силэтом и каменными карнизами.
- **Декор**: 3 дерева, пруд с искрами, цветы, кусты, валуны.
- **Костёр**: живое мерцающее пламя, частицы огня и дыма, тёплый
  `PointLight` с тенями.
- **Небо**: 14 облаков, которые медленно кружат вокруг острова, и парящие
  камни под ним, которые покачиваются.
- **Свет** (главная фишка):
  - `Lighting.ClockTime = 16.3` — тёплый закат;
  - тени прохладно-фиолетовые, отражённый свет тёплый
    (`Ambient` / `OutdoorAmbient` / `ColorShift_Top`);
  - `Atmosphere` — тёплая дымка вблизи и синева вдали (`Color` / `Decay`);
  - `BloomEffect` + `SunRaysEffect` — свечение и лучи солнца;
  - `ColorCorrectionEffect` — лёгкая «плёночная» цветокоррекция.

## Конфиг

В начале скрипта есть таблица `CONFIG` — крути её под себя:

| Параметр | Что делает |
| --- | --- |
| `IslandPosition` | где центр острова, `Y` = высота в небе |
| `GrassRadius` | размер острова |
| `ClockTime` | время суток (6 — рассвет, 12 — полдень, 18 — закат) |
| `Brightness` | яркость солнца |
| `ExposureCompensation` | экспозиция |
| `CloudCount` / `FloatingRockCount` | сколько облаков и парящих камней |

## Идеи на следующий шаг

- Плавная смена дня и ночи (крутить `ClockTime` в `Heartbeat`).
- Водопад, стекающий с края острова в облака.
- Монетки для сбора и счётчик на `ScreenGui`.
- Двойной прыжок или планер — чтобы летать между островами.
- Второй остров побольше и мост между ними.
