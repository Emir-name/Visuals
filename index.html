Что внутри

Не читы. Только визуал.

Всё, что делает мод, видно только на экране — никаких преимуществ в игре, никаких пакетов чужим клиентам.

Установка

Четыре шага

Как и любой Fabric-мод — никакой особой магии.

1

Поставь Fabric Loader

Скачай и запусти установщик с fabricmc.net для версии 1.21.4.

2

Поставь Fabric API

Мод на него опирается — без него не запустится. Тоже кладётся в mods.

3

Скачай Impact Visuals

Возьми .jar со страницы релизов на GitHub — кнопка выше.

4

Положи в папку mods

%appdata%/.minecraft/mods на Windows — и запускай профиль Fabric.

i

Текущая версия: v1.0.0 — файл impactvisuals-1_0_0.jar лежит прямо рядом со страницей. При обновлении мода просто замени файл в репозитории на новую версию с тем же именем ссылки — или поменяй имя файла и в кнопке выше.
